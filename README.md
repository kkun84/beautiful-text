# Beautiful Text

A minimalist static site for beautifully displaying text with Markdown support.

## Features

- **URL-based sharing**: All text is encoded in the URL for easy sharing
- **Automatic Markdown detection**: Detects markdown when:
  - Line 1 starts with `# `
  - Line 2 is empty
  - Line 3 is not empty
- **GitHub-style rendering**: Rich markdown display inspired by GitHub
- **Copy-paste friendly**: All markdown symbols preserved (except links)
- **Real-time preview**: See changes as you type

## Usage

Visit the site and start typing. Your text will automatically be saved to the URL.

Share the URL to share your text with others.

## Deployment

This site is deployed on GitHub Pages and requires no build step.
